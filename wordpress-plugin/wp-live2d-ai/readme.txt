在博客左下角显示 Live2D AI 助手，对话由独立的 Python 服务提供。

== 安装 ==

1. 先在仓库根目录执行 `pnpm --dir frontend build`，生成 `assets/app/` 构建产物。
2. 把整个 `wp-live2d-ai` 文件夹上传到 WordPress 的 `wp-content/plugins/`。
3. 在后台「插件」中启用。
4. 打开「设置 → Live2D 小助手」，确认 AI 服务地址（默认 `/ai-api`）。

== 登录凭证 ==

0.2.0 起，小助手会读取 WordPress 的登录状态，并向 `wp-json/l2d-ai/v1/token`
换取一个 15 分钟有效的 JWT。签名密钥需要手动配置：

1. 执行 `openssl rand -hex 32` 生成随机值。
2. 在 `wp-config.php` 中添加 `define( 'L2D_AI_JWT_SECRET', '生成的值' );`。
3. 把同一个值写进后端 `.env` 的 `L2D_AI_JWT_SECRET`。

两处不一致时，后端会拒绝所有 token。设置页会提示密钥是否已配置，
但永远不会显示密钥内容。

== 反向代理 ==

生产环境建议用 Nginx 把 `/ai-api/` 转发到 Python 服务，避免跨域：

    location /ai-api/ {
        proxy_pass http://127.0.0.1:18080/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;          # SSE 流式输出需要
        proxy_read_timeout 300s;
    }

== 模型 ==

把 Cubism 3/4 模型放到 `frontend/public/live2d/models/<模型名>/`，
构建时会自动复制到插件的 `assets/app/live2d/models/`。

Spine 4.2 模型放在 `frontend/public/spine/models/<模型文件夹>/`，
需要骨架 JSON、同名 atlas 和贴图。构建时会生成
`assets/app/spine/models/manifest.json`，只复制运行所需文件。
在「设置 → Live2D 小助手 → 形象引擎」里切换 Live2D / Spine；
Spine 加载失败会自动回退 Live2D。

== 更新日志 ==

= 0.4.0 =

- 新增每日对账任务：对比上次见过的用户名单和当前账号，清理已删除账号
  在后端的 QQ 绑定与聊天记忆。首次运行只记录名单，不删除数据。
- 删除用户后的清理改用插件内系统令牌，WP-CLI（`wp user delete`）或程序化
  删除也能立即生效，不再依赖管理员登录态；失败时由次日对账补上。

= 0.3.9 =

- 修复个人资料页底部「更新个人资料」按钮点击无效：0.3.8 只处理了账号设置
  卡片，QQ 绑定卡片和邮箱验证卡片仍在资料表单里嵌了自己的 `<form>`。
  现在所有资料页卡片都只输出按钮，真正的表单统一放到页面底部（外层表单
  之外），通过 HTML5 `form` 属性关联。

= 0.3.8 =

- 用户名 `user_login` 注册后锁定，个人资料页只显示只读值；昵称和显示名沿用
  WordPress 个人资料页自带字段，改完点「更新个人资料」生效。若原显示名就是
  昵称，保存时会自动跟随新昵称。
- 修复账号设置卡片嵌套表单导致底部「更新个人资料」按钮无反应：注销表单移到
  页面底部，用 HTML5 `form` 属性关联，两个表单不再互相嵌套。
- 注册页新增「设置密码」输入框，至少 8 位，注册后即可用该密码登录；
  同时提示用户名不可改、昵称可改。其他插件自带的注册表单没有该字段时不受影响。

= 0.3.7 =

- 新增注册邮箱验证：普通用户注册后收到验证邮件；未验证不能换小助手 token、
  生成 QQ 绑定码或继承注销账号的额度。
- 验证链接先打开确认页、点按钮才生效，避免邮箱安全网关预取链接导致 token 失效。
- 改邮箱会自动清空验证状态并给新邮箱重发；管理员可在资料页手动标记已验证。
- 升级前已存在的用户一次性视为已验证，避免现有用户被挡在门外。
- 未验证账号注销时不留额度继承记录。

= 0.3.6 =

- 个人资料页新增「账号设置」：用户可凭当前密码更改自己的用户名（支持汉字），
  也可在二次确认后注销账号；注销时文章转交给默认管理员，不会跟着删除。
- 同邮箱注销后重新注册时继承额度：每日已用取较大值、额外额度和有效会员合并、
  兑换记录一起搬；QQ 绑定和管理员身份不继承。
- 只有用户自助注销会留下继承记录；管理员删号不继承，避免垃圾账号领回额度。

= 0.3.5 =

  两个官方过滤器放行汉字，不改 WordPress 核心；纯英文用户名行为不变。
  中文用户名的作者别名自动转成 `user-<哈希>`，避免核心 50 字符上限报错。
